# cyberaka-tools
Open Source Tools from Cyberaka

## Tools

Open `index.html` in a browser to see every tool and launch one. To add a tool, put it in its own folder and add an entry to `tools.js`.

- [markdown-viewer](markdown-viewer/index.html): live Markdown preview in the browser. Type or paste on the left, see it rendered on the right, or open or drop a `.md` file. Open `markdown-viewer/index.html` directly in a browser; no build or server needed.
